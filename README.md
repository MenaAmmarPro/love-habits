# Our Habits — Love for Mena

Tiny daily rituals for the two of us, kept gently. Tick a habit each day, watch
the streak grow, and let the little weekly grid and thirty-day heatmap show how
it all adds up. Part of the **Love for Mena** collection.

**Live:** https://menaammarpro.github.io/love-habits/

## What it does

- **Add habits** with a name, a little icon and a colour (white, pink, purple, gold, sky, mint)
- **Tick today** with one tap — tap again to undo
- **Current streak** (counts back from today, or from yesterday if today isn't ticked yet)
  and **best streak** (the longest run anywhere)
- **7-day grid** showing this week at a glance
- **30-day heatmap** of every day you've kept it
- A **note** to yourself on each habit
- A **summary** of habits, done-today, best streak and every tick
- "Suggest some habits" adds a gentle starter set
- Everything is stored on the device only — no tracking, no network calls
- Installable PWA with offline support

## How it works

Habits live in `localStorage` on that device, under the key `mena-habits`. The
data shape is:

```js
{
  habits: [
    {
      id, name, icon, color, notes,
      checks: { "YYYY-MM-DD": true },   // one truthy entry per day kept
      createdAt
    }
  ]
}
```

The computation is kept in **pure functions**, exposed on `window.MenaHabits`
so they can be tested without a browser:

- `streak(checks, today)` → `{ current, best }`
- `heatmap(checks, { days, today })` → `[{ date, on, weekday, label }]`
- plus `weekGrid`, `summary`, `countChecks`, `dayISO`, `shiftDay` and friends

To change the starter suggestions, edit the `SUGGESTIONS` array at the top of
`js/app.js`.

## Files

- `index.html` — the page
- `css/theme.css` — shared love-theme (copied from `_love-theme/`)
- `css/app.css` — page-specific styles (cards, grids, heatmap)
- `js/theme-main.js`, `js/effects.js` — shared behaviour/effects
- `js/app.js` — habit logic (`window.MenaHabits`)
- `manifest.webmanifest`, `sw.js` — PWA
- `assets/` — favicon, icons (generated by `tools/make-icons.js`)
- `test/harness.js` — dependency-free Node tests

## Run locally

```powershell
py -m http.server 8000
```

Then visit http://localhost:8000.

## Test

```powershell
node test/harness.js
node --check js/app.js
```

Static site, deployed with GitHub Pages from `main`.
